Earth–Moon Transfer Analysis Using an STM-Based Low-Fidelity Costate Method

A formal research-lab presentation of a numerical framework for preliminary trajectory design, sensitivity analysis, and rendezvous targeting in low-fidelity Earth–Moon transfer problems.

Overview

This project presents a numerical framework for Earth–Moon transfer analysis based on a State Transition Matrix (STM)-driven low-fidelity costate method. The implementation is designed to support preliminary mission design, trajectory sensitivity analysis, and rendezvous targeting with low computational cost and strong numerical accuracy.

The framework combines low-fidelity transfer dynamics, STM propagation, and costate-based correction to iteratively improve terminal conditions. Numerical integration is performed with ODE113, and the current implementation achieves a terminal rendezvous error norm below 1.0e-5.

Primary Method STM-Based Costate Analysis
Integrator ODE113
Terminal Error Norm < 1.0e-5

Research Motivation

Trajectory design for Earth–Moon missions often requires repeated analysis across a wide design space. Although high-fidelity models are essential in later mission phases, they can be computationally demanding during early concept development. Low-fidelity methods therefore remain important for rapid iteration, sensitivity studies, and generation of initial guesses for more advanced optimization pipelines.

This project addresses that need by developing a lightweight yet accurate framework for transfer analysis and rendezvous correction.

Research Objectives

  • Develop a computationally efficient low-fidelity Earth–Moon transfer model.
  • Propagate state sensitivities through the State Transition Matrix.
  • Apply costate-based correction to reduce terminal mismatch.
  • Support preliminary rendezvous design with high numerical accuracy.

Methodology

The implemented framework follows a sensitivity-based correction strategy for transfer design. The state and associated variational dynamics are propagated numerically, enabling construction of the STM. This matrix characterizes the sensitivity of the terminal state to perturbations in the initial condition. Based on this information, a costate-based update is used to iteratively refine the trajectory and reduce rendezvous error.

  • Low-fidelity trajectory propagation
  • STM computation and propagation
  • Costate-based terminal correction
  • ODE113 integration
  • Terminal error norm evaluation

Numerical Performance

Preliminary results indicate that the proposed method provides robust convergence and accurate rendezvous solutions in the tested scenarios. The present implementation attains a terminal rendezvous error norm below 1.0e-5, demonstrating the suitability of the framework for early-stage mission design and research-oriented trajectory studies.

Research Significance

This framework is intended to support:

  • Rapid transfer trajectory prototyping
  • Sensitivity and convergence studies
  • Generation of initial guesses for higher-fidelity solvers
  • Educational and research applications in orbital dynamics and mission design
